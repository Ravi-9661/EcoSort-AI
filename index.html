🧠 How the AI Logic Works

  1. Normalize the user's waste description.
  2. Match sustainability keywords against a lightweight rule-based knowledge model.
  3. Predict a category and confidence score.
  4. Return a disposal recommendation and estimated eco points.

This demo intentionally uses transparent local AI logic so it works without API keys. It can later be connected to an LLM such as IBM Granite.
